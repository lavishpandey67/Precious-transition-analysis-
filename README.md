# Support Request Handling — Standard Operating Procedure

A standard operating procedure defining how customer/client support requests should be received, triaged, resolved, and closed — written to practice structured process documentation and requirements mapping.

## What's Inside

- **Purpose & Scope** — what the process covers
- **6-step process** — intake → categorization → assignment → resolution → verification → closure
- **Priority & response time matrix** — Critical / High / Medium / Low, with defined SLAs
- **Escalation path** — 3-tier, with clear triggers for each level
- **Roles & responsibilities** — who owns what at each stage
- **Record-keeping requirements** — audit trail and retention standard

## Why This Exists

Written to demonstrate structured process thinking and documentation skill — the kind of work that sits behind "process documentation" and "requirements mapping" as resume skills, rather than leaving those as unproven claims.
