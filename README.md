# Precious Metals Transaction Analytics

Data consolidation, formula-driven financial modeling, and strategic reporting on a structured precious metals transaction dataset — built to practice end-to-end data analysis workflows, with AI-assisted development.

> **Note on the dataset:** This uses a self-built, synthetically generated transaction dataset modeled on realistic gold & silver purchase patterns. It was created specifically to practice data consolidation, analysis, and reporting — not sourced from any real individual's financial records.

## Overview

- **176 transactions** across Gold and Silver categories
- **Jan 2024 – Jul 2026** (31 months)
- **₹16.5L** total transaction value
- Built in **Excel** (data model + dashboard) and **PowerPoint** (strategic presentation)

## Approach

1. **Dataset Construction** — Built a structured transaction dataset modeled on realistic gold & silver purchase patterns and pricing trends.
2. **Data Consolidation** — Standardized all records into one unified transaction table.
3. **Categorical Analysis** — Segmented transactions into price bands to identify entry-price concentration by category.
4. **Trend Analysis** — Built a chronological, formula-driven cumulative model to visualize spend pace over time.
5. **Synthesis** — Derived quantified findings and translated them into strategic recommendations.

## Key Findings

- **~₹9,375** average transaction size — consistent, recurring small purchases rather than lump-sum entries
- **46% / 54%** Gold / Silver category split
- **~3%** of transaction value lost to GST — a fixed, quantifiable cost
- Gold purchases concentrated mid-range rather than at price lows — flagged as a timing opportunity
