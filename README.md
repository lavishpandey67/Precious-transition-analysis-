## 📊 Project 1: Precious Metals Transaction Analytics

Data consolidation, formula-driven financial modeling, and strategic reporting on a structured precious metals transaction dataset.

> **Note on the dataset:** Self-built, synthetically generated transaction dataset modeled on realistic gold & silver purchase patterns — created to practice data consolidation, analysis, and reporting, not sourced from any real individual's financial records.

**Overview:** 176 transactions · Jan 2024 – Jul 2026 · ₹16.5L total transaction value · Built in Excel (data model + dashboard) and PowerPoint (strategic presentation)
